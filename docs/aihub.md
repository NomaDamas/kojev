# AI Hub 데이터 수동 다운로드 가이드 (선택 레인)

이 문서는 KoJev의 **선택적(optional)** 데이터 레인이다. 기본 파이프라인은
AI Hub 데이터 없이 돌아가며, 이 레인은 사용자가 직접 데이터를 내려받았을
때만 쓴다. 자동 다운로드, 크롤링, 인증 정보 저장은 어디에도 없다.

AI Hub(aihub.or.kr)의 데이터는 계정과 활용신청이 필요한 유료/조건부
공개 데이터라 코드가 대신 받을 수 없다. 아래 다섯 단계를 순서대로 따라
하면 된다.

## 다운로드 절차 (5단계)

1. **회원가입과 본인인증.** [aihub.or.kr](https://aihub.or.kr)에서 회원가입을
   하고 본인인증(휴대폰 또는 아이핀)을 완료한다.
2. **활용신청.** 원하는 데이터셋 페이지에서 활용신청을 한다. 활용 목적을
   간단히 기재하면 되고, 대부분 자동승인되지만 일부 데이터셋은 1~3일
   심사가 걸린다.
3. **API key 발급.** 마이페이지에서 AI Hub API key를 발급받는다. 이 키는
   개인 키이므로 저장소에 커밋하지 않는다.
4. **aihubshell로 다운로드.** gpu01에서 aihubshell을 받아 데이터셋을
   `/data2/jeffrey/kojev/data/aihub` 아래에 내려받는다.

   ```bash
   curl -o aihubshell https://api.aihub.or.kr/api/aihubshell.do
   chmod +x aihubshell
   ./aihubshell -mode d -datasetkey <데이터셋번호> -aihubapikey <API키>
   ```

   CLI가 동작하지 않으면 브라우저에서 직접 내려받은 뒤 `scp`로 gpu01의
   같은 경로에 올려도 된다.
5. **라이선스 확인.** AI Hub 데이터는 연구 목적 외 재배포가 금지된다.
   원본 파일, 가공된 jsonl, 파생 코퍼스 어떤 형태로도 저장소나 공개
   채널에 올리지 않는다. 학습에 쓰더라도 결과물에 원문이 새어 나가지
   않게 주의한다.

## 추천 데이터셋과 typed-decision 매핑

아래 두 데이터셋은 KoJev의 typed-decision 스키마(choice / score / noul)에
자연스럽게 대응된다.

### 1. 감성 대화 말뭉치

- **state:** 대화 발화 원문.
- **감정 choice:** "이 발화의 감정은?"에 감정 레이블(기쁨, 슬픔, 분노,
  불안 등)을 옵션으로 둔 choice 문항. gold는 원본 감정 라벨.
- **감정 강도 score:** 동일 발화에 대해 2~10 단계의 강도 문항으로
  환산할 수 있다. 원본에 강도 정보가 없으면 이 문항은 생략한다.

### 2. 민원(콜센터) 질의응답

- **state:** 민원 상담 질의 원문.
- **의도 choice:** "이 민원의 의도(문의 유형)는?"에 상담 유형 라벨을
  옵션으로 둔 choice 문항. gold는 원본 유형 라벨.
- **긴급도 score:** "이 민원의 긴급도는?"을 2~10 단계 score 문항으로
  둔다. 원본에 긴급도 라벨이 없으면 규칙 기반(반복 민원, 민원 키워드
  강도)으로만 만들고, 근거를 메타에 남긴다.

## 인제스션 훅

다운로드가 끝나면 `kojev.data_aihub.load_aihub_examples()`가 진입점이다.
디렉터리가 없거나 파서가 아직 없으면 이 문서를 가리키는
`NotImplementedError`를 던진다. 이 레인은 선택 사항이라 예외가
파이프라인을 막지 않는다.
