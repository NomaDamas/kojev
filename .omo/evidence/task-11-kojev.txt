
## Resume-path correction

### RED proof against the pre-fix runner

A regression test was added with a seeded usage ledger record whose request ID was `already-issued`. Before the fix, the test failed because the runner still called the transport and wrote a new label:

```text
FAILED test_seeded_request_id_skips_transport
assert labeled == 0
E       assert 1 == 0
RED_EXIT=1
```

### Fix

`kojev/label.py` now:

- Computes deterministic candidate IDs from state plus the question family using SHA-256.
- Reads issued request/candidate IDs from the ledger before constructing waves.
- Reads candidate IDs and completed states from output before constructing waves.
- Filters candidates before any transport call.
- Preserves bounded waves, per-wave persistence, timeout retry, and the existing teacher client unchanged.
- Stores the deterministic candidate ID in each output record while retaining the provider request ID in the question metadata/output request field.
