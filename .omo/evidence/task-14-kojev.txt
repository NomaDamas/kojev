DESIGN DECISIONS
- EvaluationError is a plain RuntimeError subclass with classmethod
  constructors, matching kojev/bench.py's BenchmarkError and satisfying
  TRY003/EM102 without suppressions. Deliberately not a frozen dataclass: todo 9
  proved those reject __traceback__ assignment.
- A missing or unusable checkpoint fails BEFORE any evaluation work starts. An
  evaluation report full of zeros is worse than no report, so an empty
  directory or empty file is rejected as explicitly as an absent path.
- Contamination is checked per split BEFORE scoring, and the report file is only
  written after every split passes. A contaminated run leaves no report behind.
- Latency is measured with time.perf_counter around the real model call, and is
  reported as p50/p95 in milliseconds. No duration is fabricated or hardcoded,
  and no test asserts a specific duration, so the suite cannot flake on timing.
- Metric computation reuses kojev.bench.calibration_metrics rather than
  reimplementing accuracy/Brier/ECE.

TEST COVERAGE (tests/test_evaluate.py, 8 tests)
  - missing checkpoint raises EvaluationError naming the path; asserts
    `type(exc) is EvaluationError`, not merely that something raised
  - empty checkpoint directory rejected
  - contamination check FAILS when a train state is injected into the evaluated
    split, and the message names the offending state
  - contamination check passes on disjoint states
  - HAND-COMPUTED METRICS: three questions, two correct at p=0.75 on gold and
    one incorrect at p=0.25 on gold.
      accuracy = 2/3                      (asserted to 1e-9)
      brier    = (0.125+0.125+1.125)/3
               = 0.4583333333333333       (asserted to 1e-9)
    This asserts arithmetic, not mere key presence, so a plausible-looking but
    wrong table cannot pass.
  - report carries overall/kinds/sources tables plus latency; per-kind "noul"
    and per-source "e9t/nsmc" breakdowns present; latency count exact and
    p50/p95 finite
  - missing split file raises the typed error
  - END-TO-END contamination refusal: a state present in both train and test
    aborts the run AND leaves no report file on disk (asserted
    `not out.exists()`)

ADVERSARIAL CLASSES PROBED

  silent failure     : zero-filled report impossible; checkpoint validated first
  stale state        : contaminated split proven to abort before writing output
  misleading success : exact hand-verified accuracy and Brier asserted
  flaky tests        : latency asserted finite only, never a specific duration
